# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

PMSM (Permanent Magnet Synchronous Motor) FOC (Field Oriented Control) driver firmware for STM32F407IGTx. Uses ST Motor Control SDK v6.4.2 with CANopen/CiA 402 communication. Target hardware is a custom board with 24V 3-shunt power stage and 1000 PPR quadrature encoder.

## Build System

**Keil MDK-ARM (uVision)** is the primary build system. There is no CMake or Makefile for the main firmware.

- Project file: `pmsm_foc_driver/MDK-ARM/pmsm_foc_driver.uvprojx`
- Debugger: J-Link
- Build: Open the `.uvprojx` in Keil uVision and build (F7). No CLI build flow is available.

A Makefile exists under `CANopen/CANopenNode_STM32/` but is only for testing the CANopenNode port in isolation, not the full firmware.

## Repository Structure

The repository root wraps an STM32CubeMX-generated project in `pmsm_foc_driver/`:

- `Src/` — Application source files (main.c, motorcontrol.c, mc_tasks.c, HAL peripheral init files generated by CubeMX)
- `Inc/` — Project headers
- `MDK-ARM/` — Keil project, startup assembly, linker scatter file
- `BSP/` — Board support (CAN BSP, currently legacy/test code)
- `CANopen/CANopenNode/` — CANopenNode stack (git submodule)
- `CANopen/CANopenNode_STM32/` — STM32 port: CAN driver, CANopen app layer, CiA 402 profile, Object Dictionary
- `MCSDK_v6.4.2-Full/` — ST Motor Control SDK library sources and headers
- `Drivers/` — STM32 HAL and CMSIS
- `ftl/` — FreeMarker templates used by ST MC Workbench for code generation

## Architecture

### FOC Control Pipeline

The motor control runs at 16 kHz PWM frequency in interrupt context:

1. **TIM1 UP interrupt** triggers ADC injected conversion
2. **ADC ISR** (`stm32f4xx_mc_it.c`) executes FOC: current sampling -> Clarke transform -> Park transform -> PI (Id, Iq) -> inverse Park -> SVPWM -> PWM duty update
3. **Speed PID loop** runs at medium frequency, feeding Iq reference
4. **Position loop** runs at 1 kHz, feeding speed reference

Key files: `Src/mc_tasks_foc.c` (FOC tasks), `MCSDK_v6.4.2-Full/` (PID, transforms, current sensing), `Src/stm32f4xx_mc_it.c` (interrupt handlers).

### CANopen / CiA 402 Integration

```
CAN Bus <-> CO_driver_STM32 <-> CANopenNode Stack <-> OD (Object Dictionary)
                                                              |
                                                       CiA 402 Profile (CIA402.c)
                                                              |
                                                       ST MC API (mc_api.c)
```

- **CANopen app layer** (`CO_app_STM32.c`): Init, 1ms timer (TIM14 ISR for PDO processing), main-loop process function
- **CiA 402 profile** (`CIA402.c`): Full drive state machine (NOT_READY -> SWITCH_ON_DISABLED -> READY -> SWITCHED_ON -> OPERATION_ENABLED), supports PV/CSV (velocity), PP/CSP (position), PT/CST (torque) modes
- **Object Dictionary** (`OD.h`/`OD.c`): Auto-generated by CANopenEditor. Maps CiA 402 entries (0x6040 Controlword, 0x6041 Statusword, 0x6060 Mode, 0x60FF Target Velocity, 0x607A Target Position, etc.)
- **CAN config**: Node ID 16 (0x10), 500 kbps

The motor is **not** auto-started from `main.c` — it is controlled exclusively through the CiA 402 state machine over CANopen.

### GPIO Usage

- **PWM**: PA8/PA9/PA10 (UH/VH/WH), PB13/PB14/PB15 (UL/VL/WL)
- **Encoder**: PC6 (A), PC7 (B) on TIM3
- **Current sensing**: PB0 (U), PA6 (V), PA3 (W)
- **Bus voltage**: PB1
- **Driver enable**: PF10
- **CAN**: CAN1
- **LEDs**: PE0 (LED0), PE1 (LED1)

## Conventions

- Files generated by STM32CubeMX have regeneration headers — do not hand-edit regions marked as CubeMX-generated unless you understand the consequences. Re-generate via the `.ioc` file instead.
- The ST MC Workbench generates motor control parameters. Motor/control tuning changes should be done through the `.stwb6` project, not by directly editing parameter headers.
- CANopen Object Dictionary (`OD.h`/`OD.c`) is auto-generated by CANopenEditor from `DS301_profile.xpd`. Modify the `.xpd` file and regenerate rather than editing OD files directly.
- `CANopen/CANopenNode/` is a git submodule — do not modify its contents locally.

## Motor Parameters (reference)

- 4 pole pairs, Rs=0.59 ohm, Ls=0.66 mH, max 6000 RPM, nominal 10A
- Default control mode: speed (1440 RPM target)
- Three-shunt current sensing, 0.02 ohm shunt, 6x gain
